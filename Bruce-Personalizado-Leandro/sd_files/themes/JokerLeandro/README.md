# Joker Leandro — tema selecionável no cartão SD

Copie esta pasta completa para `/themes/JokerLeandro` no SD. No Bruce, selecione:

**Configurações → Tema da interface → Cartão SD → themes → JokerLeandro → theme.json**.

O JSON configura as cores, as 16 imagens e `boot_img: boot.gif`. Não precisa editar o JSON nem gravar as imagens dentro do `.bin`. A seleção é salva; mantenha o cartão inserido e reinicie para ver a abertura. Desative **Início rápido** para não pular a animação. Para remover o tema, selecione **Padrão** no menu de temas.

- PNGs: 306×186, para o centro do menu na tela 320×240 em paisagem.
- `label: false`: o nome do módulo já está desenhado na imagem.
- GIF: 320×240, 120 quadros, 6 segundos nominais, texto **Custom by Leandro**.
- Firmware deste pacote: reprodução única do GIF na tela física completa; binários antigos podem cortar a duração/altura.
- Esta é uma composição gráfica em estilo estêncil/colagem, usando as referências fornecidas pelo proprietário. Não é filmagem de ator nem cena gerada por IA.

O tema fornece arte; ele não ativa módulos ausentes. Cabeçalho, estados e rodapé são desenhados pelo firmware. Funcionamento real e tempo de leitura ainda dependem do cartão e da montagem.

Consulte `LEIA-ME-LEANDRO.md` na raiz do projeto para compilação, gravação e pinagem.
